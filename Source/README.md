## 🚀 Projeyi Çalıştırma

Bu projeyi yerel makinenizde çalıştırmak için aşağıdaki adımları izleyin:

### Ön Gereksinimler

- [Node.js](https://nodejs.org/) (Versiyon 18 veya üzeri önerilir)

### Kurulum

1. Projeyi klonlayın veya indirin.
2. Proje dizininde terminali açın ve bağımlılıkları yükleyin:

```bash
npm install
```

### Geliştirme (Development)

Geliştirme sunucusunu başlatmak için:

```bash
npm run dev
```

Tarayıcınızda `http://localhost:5173` (veya terminalde belirtilen port) adresine gidin.

### Production Build

Canlı ortam için optimize edilmiş build almak isterseniz:

```bash
npm run build
```

Build sonucunu önizlemek için:

```bash
npm run preview
```
